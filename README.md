# Arpan Tiwari Portfolio 🚀

A modern responsive developer portfolio built using React, Tailwind CSS, Framer Motion and EmailJS.

## Features

- Modern UI with animations
- Responsive design
- Project showcase
- Coding profiles integration
- Contact form with EmailJS
- Smooth scrolling navigation

## Tech Stack

Frontend:
- React.js
- Tailwind CSS
- Framer Motion
- Vite

Tools:
- Git
- GitHub
- Vercel
- EmailJS
